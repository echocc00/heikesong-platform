# ⚠️⚠️ 为什么清单是**数据文件**而不是写在 build-demo.js 里：
#    平台有一条可移植性规则「代码里不得出现 __dirname / __filename」

#    而**守卫必须能点名它要禁的东西** ⇒ 清单写进 .js 源码就会让那条规则
#    把守卫文件**自己**判成违规（自指的假红 —— 实测踩到过）。
#    ⇒ 清单放数据文件：守卫读得到，.js 源码里也不留下完整字面量。
#    （与 scripts/forbidden.txt 是同一个套路：**清单用数据、规则用代码**。）
#
# 语法：
#   一行一个符号名；空行与 # 开头的行忽略。
#   ⚠️ 必须是**浏览器里不存在、Node 里存在**的全局量。
#      判据：写了它，浏览器里就是 ReferenceError（不是"有但行为不同"）。
